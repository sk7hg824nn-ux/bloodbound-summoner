# Akari — first combat kit

Ash coordinates. Akari fights. No fist. E-rank. One tail if the story still says one tail.

## In the kit now
- Fox Instinct — she reacts. Not a puppet animation.
- Fox Step — short reposition. Not a teleport. Not i-frames.
- Fox Cut — modest close strike. Proof she is fighting, not a number.
- Afterimage — one visible lie. Enemy can hit it. Miss. Real fox is elsewhere. Centerpiece.
- Stand — Ash occupies a square the enemy wants.
- Call — PACT points at which fox is real. Communication, not Skill 4.
- Step — DODGE moves Ash. The lie can stay.
- Commit — ATK. If the bait was taken, punish. If not, Fox Cut. Never Ash's fist.

## Not yet
Snap. Nine tails. Multi-image. Foxfire system. Teleport spam. Clone DPS. Ult. Tail damage. Command wheel.

## Two scenes
Wilderness rite: circle, drop, fail, walk, strike starts, she kills it before impact. That is a save.
Beginner ring: the loop the player learns. Trust the fox.
