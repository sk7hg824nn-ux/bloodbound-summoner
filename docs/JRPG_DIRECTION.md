# Bloodbound — JRPG direction

A full-scale, story-driven JRPG in the cinematic shape of Final Fantasy.
Built as illustrated 2.5D on a phone. Not a 2D action RPG that we later inflate.
Not a 3D production. Not a copy of those games' plots, jobs, or monsters.

2.5D means the camera can travel the layer stack:
BACKGROUND → DISTANT BUILDINGS → TREES / ARCHITECTURE → NPCs → ASH + COMPANIONS → FOREGROUND

Player brick remains the floor. It is not discarded. It is what the rest of the engine stands on.
