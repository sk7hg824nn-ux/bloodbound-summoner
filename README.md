# Bloodbound Summoner

Godot 4 / Xogot project. Landscape mobile. Player brick.

Open `project.godot` in Xogot after a clone/pull.

Flow: Boot → Character Create → Childhood yard → Academy courtyard.

Same `Player` class in both eras (`GameState.era` = child | academy).

On a computer: WASD or arrows to walk. E talk. Space dodge. J attack. K pact.
On the phone: use the on-screen stick and buttons.

Combat is not this brick.
