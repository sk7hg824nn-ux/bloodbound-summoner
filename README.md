# The Bloodbound Summoner

2D action RPG + academy life sim + dating comedy for **iPhone**, built in **Godot 4 / Xogot**.

A summoner everyone believes is powerless discovers that their ancient blood does not summon creatures — it forms **pacts with people**.

Repo: https://github.com/sk7hg824nn-ux/bloodbound-summoner

## Open in Xogot from GitHub

`project.godot` is at the **repo root**. That is what Xogot needs.

### Working Copy (usual path on iPhone)

1. Install [Working Copy](https://workingcopy.app).
2. Clone `https://github.com/sk7hg824nn-ux/bloodbound-summoner.git`
3. In Xogot: **Open Project** → the Working Copy folder for this repo.
4. Play.

### Xogot directly

If your Xogot build can open a GitHub folder or an iCloud copy of the clone, point it at the folder that contains `project.godot` — not a parent folder.

Pull after each push to stay current:

```
git clone https://github.com/sk7hg824nn-ux/bloodbound-summoner.git
```

Portrait. Touch stick left. **TALK / PACT / ATK / DODGE** right.
Desktop: WASD, E talk, J/Space attack, K dodge, L pact.

## What works right now

- Character create (name + male/female)
- Walkable academy campus
- Act I: exam humiliation → Rin → Foxwood Gate pact with Akari → beginner tournament → Cael
- Pact + bond + tails + foxfire
- Full 12-act campaign encoded in `docs/STORY.md`

## Design rule

The protagonist and the player discover the truth together. Do not explain the bloodline in UI.
